# Code of Conduct

We want Inference Gateway to be a welcoming place to learn, report problems and contribute.
Treat people with respect regardless of experience, identity, background or viewpoint.

Be constructive and specific. Critique ideas and code rather than people. Accept feedback,
acknowledge mistakes, and give others room to participate. Harassment, threats, discriminatory
remarks, sexualized behavior, disclosure of private information and sustained personal attacks
are not acceptable.

This policy applies to repository issues, pull requests, discussions and other project spaces.
Maintainers may edit or remove content, close discussions, restrict participation or ban
participants when necessary. Responses should reflect severity and repeated behavior; credible
threats or serious harassment can require immediate exclusion.

To report a concern, contact a repository maintainer privately using the contact information
on their GitHub profile. Include relevant links, dates and the behavior involved; do not post
private details in public issues. If a maintainer is involved, contact another maintainer or
an organization owner. Reports should be handled discreetly, and retaliation is prohibited.

Maintainers are responsible for applying these expectations consistently and respectfully.
